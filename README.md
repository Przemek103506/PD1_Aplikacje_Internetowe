# Aplikacje internetowe - praca domowa 1

## Serwis Komputerowy

Opis:
Przedstawiam responsywną, statyczną stronę Serwisu Komputerowego, która pełni rolę jego wizytówki.

Strona składa się z kilku interaktywnych elementów, gdzie część z nich odpowiada za nawigację po stronie oraz jej czytelność (zmiana motywu), zaś druga część przedstawia treść oraz pozwala na komunikację pomiędzy firmą a klientem. Poza tym strona w pełni dostosowuje się do urządzeń mobilnych.

## Wykorzystane tchnologie

* **HTML5** - utworzenie poprawnej struktury dokumentu z wykorzystaniem odpowiednich znaczników.
* **CSS3** - utworzenie stylów z wykorzystaniem układów takich jak **Flexbox** oraz **CSS Grid**, wykorzystane zostały również zmienne CSS w celu ułatwienia zmiany motywów oraz Media Queries dla zapewnienia pełnej responsywności.
* **JavaScript** - dodanie interaktywności na stronie:
    * Obsługa menu rozwijanego dla urządzeń mobilnych.
    * Obsługa przełącznika motywu (jasny / ciemny), z opcją zapamiętywania wybranego wcześniej motywu.
    * Obsługa formularza poprzez walidację wprowadzanych danych.
    * Obsługa dynamicznego okienka (Modal) służącego do wyświetlania informacji oraz zdjęć dotyczących zrealizowanych usług.
